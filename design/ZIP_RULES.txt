[납품 규칙 — zip 폴더 구조와 자르는 방법]
그림은 실제 게임 파일처럼 아래 폴더 구조의 zip 하나(또는 여러 개)로 보내 주세요.
게임 쪽에서 파일 이름으로 자동 인식하므로, 폴더·파일 이름이 다르면 적용할 수 없습니다.

1. zip 안의 폴더 구조 (이름 그대로, 영문 소문자)

mnbrpg_art/
├─ icons/                     ← 아이콘: 한 아이템 = PNG 한 장 (128×128, 투명 배경)
│   ├─ equipment/             nov_*.png, job_*.png              (장비 699 중 세트 제외 591)
│   ├─ set/                   set_*.png                          (세트 장비 108)
│   ├─ material/              mat_*.png                          (몬스터·대장간·보스 재료)
│   ├─ consumable/            potion_*.png, item_*.png           (물약·주문서·부적·온천·입장권)
│   ├─ ui/                    ui_*, home_*, talk_*, todo_*, mission_*, kind_*, attr_*, tab_*, fx_*  (64×64)
│   └─ skill/                 skill_*.png                        (스킬 299, 64×64)
├─ npc/                       ← NPC 안내원: 자세·표정 스프라이트 시트 한 장씩 (자르지 말고 시트 그대로)
│   └─ npc_<코드>_sheet.png    코드: shop·smith·onsen·inn·training
│                             6열(표정) × 3행(자세) = 18컷, 칸 크기 모두 같게(권장 512×640), 여백 0px
├─ backgrounds/               ← 배경: 780×1120 (시설 위쪽 그림은 780×600), 배경 그대로(투명 아님)
│   bg_ground_0~9 · bg_deep_0~9 · bg_boss_0~9 · bg_shop · bg_smith · bg_onsen · bg_inn ·
│   bg_training · bg_jobchange · bg_promo · bg_title
├─ characters/                ← 캐릭터 스프라이트 시트 (자르지 말고 시트 한 장 그대로)
│   ├─ char_<코드>_front.png, char_<코드>_back.png        (직업 31종 + 여캐)
│   └─ novice/                char_novice_body_*, char_novice_hair_*, char_novice_weapon*_*,
│                             char_novice_fist_*, char_novice_f_*
├─ monsters/                  ← 몬스터 시트 mon_m0~m19.png (시트 그대로)
├─ bosses/                    ← 보스 시트 boss_b0~b9.png (시트 그대로) + 등장 컷 boss_b0~b9_intro.png
├─ cards/                     ← card_m0~m19.png (몬스터 카드), card_b0~b9.png (보스 카드),
│                               card_frame_1.png · card_frame_2.png · card_frame_3.png (★1·★2·★3 테두리), card_back.png
├─ preview/                   ← 확인용 미리보기 (여기에만 글씨 허용)
│   폴더마다 한 장씩: preview_equipment.png, preview_set.png … 한 줄에 10개, 그림 아래 "파일 이름"
├─ manifest.csv               ← 넣은 파일 전부: 폴더, 파일 이름, 아이템 이름, 가로×세로(px), 메모
└─ missing.txt                ← 이번에 못 넣은 파일 이름 목록 (없으면 "없음")

2. 자르는 방법 — 종류마다 다름
- 아이콘(icons/): 반드시 한 장에 하나. 여러 개를 한 이미지에 모아 보내면 안 됨.
  128×128 캔버스 가운데에 놓고 가장자리 8px 여백. (ui·skill은 64×64)
  옆 아이템 조각·이름표·번호·체크무늬가 들어가면 안 됨. 아이템이 잘리면 안 됨.
- NPC(npc/): 18컷 시트 한 장 그대로. 모든 칸 크기·몸 위치가 같아야 함(컷을 바꿔도 몸이 튀지 않게).
- 스프라이트 시트(characters/, monsters/, bosses/): 프레임별로 자르지 말고 "시트 한 장" 그대로.
  칸 사이 여백 0px, 모든 칸 크기 같게(캐릭터·몬스터 96×96, 보스 160×160),
  줄 = 동작(문서의 행 순서), 칸 = 프레임(왼쪽부터). 남는 칸은 투명으로 비워 둠.
  manifest.csv의 메모 칸에 "칸 96×96, 5줄, 줄마다 프레임 수 4/4/3/1/2"처럼 적기.
- 배경(backgrounds/): 자르지 않은 한 장. 사람·몬스터·글씨 없이.
- 카드(cards/): 그림 한 장(400×600). 테두리·뒷면은 따로.

3. 파일 공통
- PNG만. 배경 이외에는 진짜 투명(알파) 배경.
- 파일 이름은 영문 소문자·숫자·밑줄(_)만, 목록에 적힌 이름 그대로. 한글·띄어쓰기·번호만 붙인 이름 금지.
- 도트는 확대할 때 NEAREST(가장 가까운 픽셀)로만. 흐리게 늘리면 안 됨.
- 같은 그림을 두 파일에 쓰지 않기.

4. 나눠서 보낼 때
- zip 이름: mnbrpg_art_<내용>_<번호>.zip  (예: mnbrpg_art_icons_01.zip, mnbrpg_art_npc_01.zip)
- 나눠 보내도 zip 안 폴더 구조는 위와 같게(해당 폴더만 들어 있으면 됨).
- 고친 그림을 다시 보낼 때는 같은 파일 이름으로 보내면 덮어씁니다.

5. 보내기 전 스스로 확인 (결과를 한 줄씩 적어 주세요)
- manifest.csv의 파일 수 = 실제 파일 수
- 모든 파일 이름이 목록에 있는 이름인가, 폴더가 맞는가
- 아이콘 크기(128 또는 64)와 네 모서리 투명
- 글씨·번호·체크무늬 없음, 잘린 그림 없음, 중복 없음
- 시트는 칸 크기로 나누어떨어지는가(예: 가로 384 = 96×4)

[NPC 그림체 — NPC 안내원 5명에만 적용]
- NPC 안내원 5명(미아·브리·유키·세라·카린)은 "코사오풍 그림체"로 그려 주세요.
  (지금 게임의 안내원 리나 일러스트와 같은 느낌으로, 다섯 명이 한 작가가 그린 것처럼 통일)
- 애니 일러스트(도트 아님). 상반신, 정면에서 살짝 비스듬히, 시선은 화면 쪽.
- 큰 눈과 또렷한 눈동자 하이라이트, 부드러운 셀 채색 + 은은한 그라데이션, 깔끔한 선.
- 밝고 화사한 파스텔 톤, 마을 배경(따뜻한 햇살의 판타지 마을)과 어울리게.
- 자세·표정 시트 18컷(행: 기본·안내·시설 동작 자세 / 칸: 기본·웃음·놀람·곤란·윙크·인사)은 같은 크기·같은 위치·같은 옷으로, 자세와 얼굴만 바뀌게.
- 배경 없이(투명) 또는 단색 배경. 글씨·사인·워터마크 없음.
- 이 그림체는 NPC에만. 아이콘·캐릭터·몬스터·보스는 도트(라그나로크 생김새 + 메이플식 채색), 배경은 애니 일러스트.
