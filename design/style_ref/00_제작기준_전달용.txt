RPG 아트 스타일 확정 기준 / 전달용

1. 인물 일러스트: 코사오풍. 이전에 작업한 리나 캐릭터의 화풍이 기준. 현재 첨부된 참고 ZIP에는 리나 원본 시안이 포함되지 않았으므로 반드시 별도 첨부 요청. 임의의 그림체로 대체 금지.

2. 장비·아이템·스킬 아이콘: 01번 시안 기준. 라그나로크+메이플스토리 감성의 정교하고 선명한 2D 픽셀아트. 무기, 방어구, 보조장비, 장신구, 소모품, 재료/몬스터 드롭, 스킬 포함. 고유 실루엣, 또렷한 외곽선, 픽셀 단위 명암과 색감 유지. 실제 납품은 시트가 아닌 개별 투명 PNG로 구성. 픽셀 보존 확대.

3. 몬스터: 02번 시안 기준. 라그나로크 온라인 클래식 몬스터 느낌의 2D 도트. 초급은 작고 귀엽고 단순한 비율, 중급은 특징이 뚜렷한 개체, 상급·보스는 개성과 위압감을 강화하되 같은 도트 밀도 유지. 실제 게임 사용 시 대기/이동/공격/피격/사망 모션 고려. 참고 시안의 이름이나 캐릭터를 그대로 복제할 필요는 없으며 독창적인 몬스터 제작.

4. 사냥터/배틀 배경: 03번 시안 기준. 밝고 섬세한 판타지 애니메이션 일러스트풍. 포켓몬 배틀 배경 같은 원근 정면뷰, 약간 높은 눈높이의 일점투시. 쿼터뷰와 사이드뷰 금지. 최종 제작 규격은 세로 780x1120 픽셀(참고 이미지 원본 해상도와 다름). 지평선은 위에서 약 1/3, 그 아래 넓고 평평한 땅이 안쪽으로 이어짐. 오른쪽 위는 몬스터 배치용 여백, 왼쪽 아래는 플레이어 뒷모습 배치용 여백. 하단 40%는 UI가 가리므로 바닥 질감 위주. 배경 자체에는 사람/몬스터/글씨/UI 없음. 숲·사막·설원·동굴 등 환경만 바꾸고 화풍/시점은 고정.

공통 원칙: 네 스타일을 서로 섞지 말 것. 기존 699개 아이콘 작업물은 새 제작 기준으로 사용하지 않으며 새 목록 확정 후 새로 의뢰. 참고 이미지는 스타일 확인용 시안이며 개별 사용 가능한 투명 PNG/애니메이션 스프라이트로 분리된 완성 납품물이 아님.
